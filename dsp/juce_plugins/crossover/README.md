# crossover

A two-way **linear-phase FIR crossover**. Mono input. Output 1 is the low band (woofer),
output 2 the high band (tweeter).

```
in ─┬─ gain ─ FIR lp[] ─► out 1 (low)
    └─ gain ─ FIR hp[] ─► out 2 (high)
```

The taps come from `crossover_coefs.hpp` (`float lp[N]`, `float hp[N]`), compiled in. The
header is generated by the tuning GUI (*Export C++ headers*), which writes it straight into
this folder. It is designed with Parks-McClellan (`scipy.signal.remez`) at the crossover
frequency / transition width / tap count set in the GUI.

To change the crossover, re-export from the tuning GUI and rebuild:

```bash
../tools/build-podman.sh crossover            # then -install to deploy
```

The per-band delays the tuning GUI uses for time alignment are simulation-only. They are
not part of this header, so apply them in the host or in the signal chain.

| Parameter | Range | |
|---|---|---|
| Gain | −30 … 0 dB | applied to both bands |
| Freq | | unused (left over from the plugin template) |

The editor plots the combined response of the compiled-in filters.

Latency: a linear-phase FIR delays by (N − 1)/2 samples, e.g. 129 samples (2.7 ms at
48 kHz) for the shipped 259-tap design.
